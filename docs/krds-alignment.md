# KRDS 정렬 원칙

제주 디자인 시스템은 KRDS를 **접근성 및 공공서비스 패턴의 기준점**으로 참고하되 제주특별자치도의 브랜드와 업무시스템 특성을 유지한다.

## 따르는 방향

- 명확한 정보 구조와 제목 위계
- 충분한 터치 타깃
  - 대민 프로필: 실제로 누를 수 있는 영역 44×44px 이상(KRDS 캐러셀 가이드의 터치 조작 영역 권장값을 대민 공통 기준으로 사용), `--jeju-target-min`
  - 업무 프로필: WCAG 2.2 SC 2.5.8 최소 24×24px(간격 예외 허용)
- 글자 크기: 대민 본문 17px(KRDS 기본), 가장 작은 글자 13px(KRDS xsmall), 오류 문장 15px
- 키보드 접근성과 가시 포커스
- 상태를 색 하나로 전달하지 않기
- 대민 서비스의 공공기관 식별·헤더·푸터·본문 컨테이너 패턴
- 반응형·고대비·동작 감소 사용자 설정 존중

## 제주에서 별도로 정의하는 것

- 브랜드 색은 제주 포인트 3색을 사용한다.
- 업무용 화면은 대민 화면보다 높은 정보 밀도를 허용한다.
- 업무 프로필은 36px 기본 컨트롤을 사용한다.
- 대민 프로필은 48px 기본 컨트롤을 사용한다.
- 다크 모드는 v0.1 범위 밖이다.

## 주장 범위

이 프로젝트는 KRDS의 모든 컴포넌트·토큰을 동일하게 구현했다는 의미의 “완전 준수”를 주장하지 않는다. 실제 공공서비스 적용 전에는 최신 KRDS 및 KWCAG 기준과 별도로 대조·검증해야 한다.
